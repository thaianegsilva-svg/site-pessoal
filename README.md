# Thaiane Siao — Portfólio

Site pessoal estático de apresentação e portfólio. HTML, CSS e JavaScript, sem dependências de build. Conteúdo e imagens de projetos baseados no perfil público [Behance](https://www.behance.net/thaianesilva3). LinkedIn confirmado pelo solicitante: https://www.linkedin.com/in/thaiane-siao.

## Visualização local

Execute `python -m http.server 4173 --bind 127.0.0.1` na pasta do projeto e abra http://127.0.0.1:4173.

## GitHub Pages

O workflow `.github/workflows/pages.yml` publica os arquivos estáticos em cada push para `main`. No GitHub, em **Settings → Pages → Build and deployment → Source**, selecione **GitHub Actions**. Endereço esperado: https://thaianegsilva-svg.github.io/site-pessoal/.

## Edição

- Textos, links e projetos: `index.html`.
- Identidade visual e responsividade: `style.css`.
- Filtros e menu: `script.js`.
- Imagens locais: `assets/`.

O e-mail fornecido para localizar o LinkedIn não é divulgado no site. Não há formulário, coleta de dados ou rastreamento.
