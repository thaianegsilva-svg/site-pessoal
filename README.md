# Thaiane Siao — Portfólio

Site pessoal estático de apresentação e portfólio. HTML, CSS e JavaScript, sem dependências de build. Conteúdo e imagens de projetos baseados no perfil público [Behance](https://www.behance.net/thaianesilva3). Trajetória e especialidades também verificadas no perfil LinkedIn: https://www.linkedin.com/in/thaiane-siao.

## Visualização local

Execute `python -m http.server 4173 --bind 127.0.0.1` na pasta do projeto e abra http://127.0.0.1:4173.

## GitHub Pages

O workflow `.github/workflows/pages.yml` publica os arquivos estáticos em cada push para `main`. No GitHub, em **Settings → Pages → Build and deployment → Source**, selecione **GitHub Actions**. Endereço esperado: https://thaianegsilva-svg.github.io/site-pessoal/.

## Edição

- Textos, links e projetos: `index.html`.
- Identidade visual e responsividade: `style.css`.
- Filtros e menu: `script.js`.
- Imagens locais: `assets/`.

O e-mail fornecido para localizar o LinkedIn não é divulgado no site. Não há formulário, coleta de dados ou rastreamento.

## Paleta de cores

Referência Pantone Fashion, Home + Interiors, biblioteca TCX, com aproximações digitais sRGB para telas:

| Cor | Pantone | HEX | Aplicação |
| --- | --- | --- | --- |
| Swamp | 15-6310 TCX | `#A8B197` | Fundo da composição principal e superfícies derivadas |
| Chive Blossom | 18-3634 TCX | `#7E5E9A` | Selo, faixa e elementos gráficos |
| Rose Red | 18-1852 TCX | `#C82151` | Botão principal, destaques e seção de contato |

Fundos claros e texto escuro neutros complementam a paleta para legibilidade. As cores das obras do portfólio são preservadas.

Referências: [Pantone Swamp](https://www.pantone.com/na/en-us/color-finder/15-6310-tcx), [Chive Blossom e equivalente digital](https://www.colorxs.com/color/pantone-18-3634-tcx-chive-blossom), [Rose Red e equivalente digital](https://www.colorxs.com/color/pantone-18-1852-tcx-rose-red), [Swamp e equivalente digital](https://palettes.page/pantone-colors/15-6310-tcx). Cores de tela são simulações e não substituem amostras físicas Pantone.
